# 门票上品（ticket-publish）

从用户提供的文案和海报图片中提取景区门票/漂流/游乐套餐信息，自动计算结算价格和利润率，写入飞书在线表格。


## 技术栈

- Python 3
- pytesseract + tesseract（海报 OCR 识别）
- Pillow（图片处理）
- lark-cli（飞书 CLI 工具）

## 18 列结构

| 列 | 标题 | 说明 |
|---|---|---|
| A | 填写日期 | 当天日期，格式 `2026-05-12` |
| B | 景区 | 景区/酒店名称 |
| C | 渠道 | 乐潇游（门票默认） |
| D | 可上架渠道 | 立阳来客（门票默认） |
| E | 套票名称 | 从文案提取的套餐名称 |
| F | 内容 | 套餐包含内容，格式：`AAAA景区入园门票1张+所选项目套票1张。{所选项目}。入园门票含:{入园包含内容}` |
| G | 加收 | 从海报或用户提供，如"周末/节假日不加价" |
| H | 售卖时间 | 与可用日期一致（除非海报另有说明） |
| I | 可用日期 | 从海报 OCR 或用户提供 |
| J | 对外价格 | `直播价 / 0.7` 取整 |
| K | 直播价 | 从文案提取 |
| L | 结算价格&利润率 | `结算价{结算价}；利润率{利润率:.1f}%` |
| M | 备注 | `下单编号：{编号}` + 其他备注信息（加收等） |
| N | 抖音商品id | 留空 |
| O | 抖音链接 | 留空 |
| P | 海报 | 留空 |
| Q | （空） | 留空 |
| R | （空） | 留空 |

## 用户输入格式

用户提供的原始输入格式示例：

```
【周末不加价】佛山三水九道山~狂野全程漂~广东十大漂流之一！
[爱心]单人票59返6/编号41791118[强]双人票99返12/编号41795466[强]
[爱心]漂流+水上乐园单人票69返8/编号41795467[强]双人票129返15/编号41795471[强]，图片@test3.jpg
```

**处理规则：**
- 第一行为标题行，包含景区名和亮点词
- 后续每行包含套餐名 + 价格返佣 + 编号
- `图片@xxx.jpg` 指向海报图片路径

## 处理流程

### 1. 解析文案

从用户输入中提取：

| 字段 | 提取方式 |
|---|---|
| 景区名 | 标题行中提取（如"佛山三水九道山"） |
| 套餐名 | 价格前的文本（如"单人票"、"双人票"） |
| 直播价 | 匹配 `(\d+)返` 的数字 |
| 深返 | 匹配 `返(\d+)` 的数字 |
| 编号 | 匹配 `编号(\d+)` 的数字 |

### 2. OCR 识别海报

- 用 pytesseract 识别海报图片
- 提取：**适用日期**、**售卖时间**、**加收**、**备注信息**（如年龄/身高限制、营业时间等）
- **注意：** 风景图叠加文字的海报 OCR 识别效果差，需用户手动提供信息

### 3. 字段计算

| 字段 | 公式 |
|---|---|
| 对外价格 | `int(直播价 / 0.7)` |
| 结算价 | `直播价 - 深返` |
| 利润率 | `深返 / 直播价 - 5%` |
| 结算字符串 | `结算价{结算价}；利润率{利润率:.1f}%` |

### 4. 写入飞书

- 先读取 A 列获取当前行数：`lark-cli sheets +read --range "A:A"`
- 起始行号 = `len(values) + 1`
- 每个套餐写入一行，全部 18 列
- 使用 `lark-cli sheets +write` 写入

## 结算价格&利润率计算

```
对外价格 = int(直播价 / 0.7)
结算价 = 直播价 - 深返
利润率 = 深返 / 直播价 - 5%
```

示例：
- 直播价 59，深返 6 → 对外 84，结算价 53，利润率 5.2%
- 直播价 79，深返 15 → 对外 112，结算价 64，利润率 14.0%
- 直播价 99，深返 25 → 对外 141，结算价 74，利润率 20.3%
- 直播价 129，深返 15 → 对外 184，结算价 114，利润率 6.6%

## 内容列（F列）格式规范

内容列格式为：
```
AAAA景区入园门票1张+所选项目套票1张。{所选项目名称}。入园门票含:{入园包含内容}
```

示例（天露山）：
- 套餐1（飞车&小火车）：`AAAA景区入园门票1张+所选项目套票1张。天露飞车+环山小火车。入园门票含:天露山飞天瀑布、梅溪古镇、无忧谷森林栈道、梯田花谷、打卡佛手拈花、南药科普园等`
- 套餐2（小火车&漂流）：`AAAA景区入园门票1张+所选项目套票1张。环山小火车+玻璃空中漂流。入园门票含:天露山飞天瀑布、梅溪古镇、无忧谷森林栈道、梯田花谷、打卡佛手拈花、南药科普园等`
- 套餐3（飞车&漂流）：`AAAA景区入园门票1张+所选项目套票1张。天露飞车+玻璃空中漂流。入园门票含:天露山飞天瀑布、梅溪古镇、无忧谷森林栈道、梯田花谷、打卡佛手拈花、南药科普园等`

## 写入规则

1. **自动检测行号：** 读取 A 列所有值，从 `len(values) + 1` 开始写入
2. **全部 18 列必须填写：** 不留空列（无数据则填空字符串 `""`）
3. **渠道默认值：** C列渠道填"乐潇游"，D列可上架渠道填"立阳来客"
4. **备注列：** 包含 `下单编号：{编号}` + 其他备注信息（如加收说明等）
5. **售卖时间：** 默认与可用日期一致
6. **加收列：** 从海报或用户提供的信息填写，如"周末/节假日不加价"

## 注意事项

### 海报 OCR 局限性

对于**风景图叠加文字**类型的海报（如天露山景区海报），OCR（pytesseract）识别效果极差，几乎无法提取任何有效文字。遇到此类海报时：
1. 尝试一次 OCR，如果输出全是乱码/无意义字符，直接告知用户识别失败
2. 从用户提供的文案中提取所有可用信息
3. 向用户询问海报上的关键信息：适用日期、售卖时间、加收、套餐内容等
4. 不要反复尝试不同 OCR 参数浪费时间

### 全部列填写

写入飞书时必须填写全部 18 列，不能只填部分列。无数据的列填空字符串。

### 行号规则

写入时从当前最后一行的下一行开始，不指定固定行号。先读取 A 列获取当前行数，再计算起始行号。

### 渠道默认值

门票类套餐：
- **C列（渠道）：** 乐潇游
- **D列（可上架渠道）：** 立阳来客
